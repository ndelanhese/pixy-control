# Security policy

This early project currently maintains the latest source on `main`.

Report vulnerabilities using [GitHub private vulnerability reporting](https://github.com/ndelanhese/pixy-control/security/advisories/new). Include a minimal reproduction and affected commit. Do not publish camera images, recordings, serial numbers, credentials, or personal diagnostic dumps in an issue.

Camera and microphone access use the normal macOS permission flow. The app does not install a camera extension or modify system privacy databases. Manual privacy must not be opened automatically by a new consumer.
